# internal OpenAI model

**A real-world entity, not part of the novel's world: the unnamed, unreleased model that, by the account of the github.com/openai/math collection (landed 2026-10-07, decision 026), produced its mathematics manuscripts.** The collection's documents are its only sources here; each reading below is one document's, attributed and unmerged.

## Reading — `openai-math-readme`, 2026-10-06, the openai/math readme — the unnamed model that produced the collection, and what a result cost

The readme says what produced the collection: „This repository contains mathematical manuscripts and supporting proof artifacts produced by an internal OpenAI model.“ ^[openai-math-readme.md:L13] It never names or dates the model; for the procedure it calls it „an unreleased internal OpenAI model“ ^[openai-math-readme.md:L50], and `GPT` stands nowhere in it (`GPT` ^[openai-math-readme.md:#0]).

Why the model was set these problems: „As part of model development, we evaluate our models on open research problems.“ ^[openai-math-readme.md:L15] and „We expanded these evaluations after performance on our existing mathematical evaluations saturated.“ ^[openai-math-readme.md:L15] Some results rest on others: „Some outputs build upon earlier results produced by the models.“ ^[openai-math-readme.md:L15]

What it cost and how much it was asked: „On average, each result used three hours of ChatGPT Pro thinking compute with that model.“ ^[openai-math-readme.md:L50] and „Over the course of the evaluation, the model was posed approximately 4,000 problems.“ ^[openai-math-readme.md:L50] The catalogue is a selection from that output: „Aggregating the output into result families and manuscripts and requiring an appropriate level of significance led to the catalog outlined above.“ ^[openai-math-readme.md:L50]

Not everything came from that one procedure. „Exceptions to this fixed procedure include work on a zero-free region for the Riemann zeta function and proof of the Hodge Conjecture for CM abelian varieties.“ ^[openai-math-readme.md:L52] One writeup had a human hand: it „was human edited for readability“ ^[openai-math-readme.md:L52]. The readme does not say what the exceptions' procedure was.
