# Emergenz

## Reading — `aegis-emergenz-aus-der-leere`, 2025-04-19

Emergence here means **emergence from nothing**. It is the postulate's core claim
and the source's first target:

> „Die Kernbehauptungen von AEGIS sind radikal: Emergenz aus einem Zustand der
> Leere ('Nichts', ∅)" ^[aegis-emergenz-aus-der-leere.md:L19]

Formally, the initial agent state is a fixpoint of the system's own dynamics,
identified in an empty state space ^[L44].

## What the source says about it ^[L45, L47, L102]

The formalisation is judged non-rigorous, and the argument is precise:

> „Damit der Fixpunkt fix(f) formal Sinn ergibt, müssten die Funktion f" ^[aegis-emergenz-aus-der-leere.md:L45]

The source requires properties of the function and its domain before the claimed emergence.

> „Fixpunkttheoreme beschreiben Existenz *innerhalb* gegebener Strukturen, nicht
> die Erschaffung dieser Strukturen *ex nihilo*." ^[aegis-emergenz-aus-der-leere.md:L47]

And physically and philosophically:

> „Physikalisch betrachtet ist das Quantenvakuum kein echtes \"Nichts\" […]
> Philosophisch steht dem das Prinzip *ex nihilo nihil fit* […] entgegen" ^[aegis-emergenz-aus-der-leere.md:L102] ^[L102]

## Surfaces

`Emergenz` (20) beside the adjective in four inflected forms — `emergent`,
`emergente`, `emergenten`, `emergenter` (8 total) — and `Emergenzkriterium` (2).
**An exact-string index sees six terms here.**

## Reading — `kohaerenzprotokoll-aegis-und-systementropie`, 2025-04-19

Emergence **within** a system, not of one:

> „AEGIS ist plausibler ein emergentes Phänomen, das innerhalb der komplexen
> Dynamik der Simulation entstanden ist, um Informationen zu verwalten und
> Stabilität aufrechtzuerhalten." ^[kohaerenzprotokoll-aegis-und-systementropie.md:L195]

The argument is that this **explains a defect**: [[aegis|AEGIS]] developed using the
simulation's own physics and data types, so it would not develop senses for
phenomena resting on other principles ^[kohaerenzprotokoll-aegis-und-systementropie.md:L197]. See [[blinder-fleck|Ontologischer blinder Fleck]].

**→ Conflict `C3`** — `Wiki/conflicts/c3-emergenz-origin.md`. Both sources use the
word correctly and mean opposite things by it, and what it decides is whether
[[aegis|AEGIS]] can be wrong about its own world.

## Note

`Emergenz` has a settled meaning outside this project, which normally keeps a term
from drifting. **It did not help here** — the drift is in what the word is applied
to, not in the word.

## Reading — `kohaerenz-protokoll-konzeptionelle-ausarbeitung`, 2025-04-19, the conceptual report on the protocol — emergence as one of four derivation mechanisms

The conceptual report treats emergence as a mechanism in an abstract construct for any system; it names no figure, place or event of the novel. It defines it: „Emergenz beschreibt das Auftreten von Mustern, Strukturen oder Eigenschaften auf einer höheren Systemebene“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L157], and adds that it can be tied to new information: „Emergenz kann mit der Generierung neuer Information verbunden sein“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L157].

It proposes that the mechanisms combine: „Emergenz kann aus der rekursiven Anwendung von Regeln resultieren“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L190]. It contrasts generation of information in emergence with reduction in self-organisation: „Informationsgenerierung“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L194] against „Informationsreduktion“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L194], a balance it says the protocol must manage.

On architecture it says of a protocol based on emergence: „Wenn das Protokoll auf Emergenz basiert“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L244] its function would be distributed. It leaves the protocol's own status open: „Handelt es sich beim Protokoll um eine emergente Eigenschaft“ ^[kohaerenz-protokoll-konzeptionelle-ausarbeitung.md:L445].
