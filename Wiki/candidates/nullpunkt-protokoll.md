# Nullpunkt-Protokoll

One of eight protocols of an „AEGIS-Postulat" ^[L11] that the only source **analyses
rather than authors**. So every reading is doubly attributed: what the postulate
claims, and what this source says about the claim.

## What the postulate claims — **Beschreibung** ^[aegis-emergenz-aus-der-leere.md:L44]

emergence of an agent system from an empty state `S₀ = ∅` by recursive self-reference, with the initial state identified as a fixpoint `A₀ := fix(f)`.

That label marks the postulate's content, **not this document's position**.
Asserting it of this source would attribute to it the thing it goes on to reject.

## What the source says about it — **Bewertung** ^[aegis-emergenz-aus-der-leere.md:L47]

Fixpoint theorems describe existence *within* given structures, not the creation of those structures *ex nihilo*.

> „Die Analogie zu Gödel und Löb ist ebenfalls problematisch; deren Theoreme gelten für hinreichend ausdrucksstarke formale Systeme, die Arithmetik umfassen können, nicht aber für eine ontologische Leere." ^[aegis-emergenz-aus-der-leere.md:L45]
