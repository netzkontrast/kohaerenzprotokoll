# ANI — Äußere Nicht-Identifikation

One of eight protocols of an „AEGIS-Postulat" ^[L11] that the only source **analyses
rather than authors**. So every reading is doubly attributed: what the postulate
claims, and what this source says about the claim.

## What the postulate claims — **Beschreibung** ^[aegis-emergenz-aus-der-leere.md:L85]

protection against external takeover: inputs mappable onto internal memory are rejected when their coherence falls below a threshold.

That label marks the postulate's content, **not this document's position**.
Asserting it of this source would attribute to it the thing it goes on to reject.

## What the source says about it — **Bewertung** ^[aegis-emergenz-aus-der-leere.md:L88]

It blocks the learning and adaptation an AGI requires.

> „Wie kann das System überhaupt Informationen über eine externe Welt erwerben, wenn Inputs allein aufgrund mangelnder *interner* Kohärenz zurückgewiesen werden?" ^[aegis-emergenz-aus-der-leere.md:L88]
