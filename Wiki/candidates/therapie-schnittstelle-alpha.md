# Therapie-Schnittstelle Alpha

The interface through which Kael is given therapy in KW1 — and, the document proposes, monitored.

## Reading — `roman-lokalitaeten-konzept-und-ausarbeitung`, 2025-04-18

The master list gives four facts in one row ^[roman-lokalitaeten-konzept-und-ausarbeitung.md:L190]:

| | |
|---|---|
| Realitätsebene | `KW1` |
| where the name came from | `Plot Teil 1` |
| function, in brief | „Ort der (manipulierten) Selbstreflexion, Kontakt zum Therapeuten" ^[roman-lokalitaeten-konzept-und-ausarbeitung.md:L190] |
| associated characters | Kael, Therapeut (NPC), LogOS (System) |

The profile states the double function directly:

> „Dient der Systemintegrität durch (vermeintliche) psychologische Betreuung,
> potenziell aber auch der Überwachung und Manipulation von Kaels Zustand."
> ^[roman-lokalitaeten-konzept-und-ausarbeitung.md:L294]

and draws the consequence:

> „Der Raum selbst ist eine Schnittstelle, kein Ort echter menschlicher
> Begegnung. Die potenzielle Manipulation hier untergräbt das Konzept von
> Therapie." ^[roman-lokalitaeten-konzept-und-ausarbeitung.md:L297]

The `Therapeut` is an NPC reached through it and is „vermutlich ebenfalls
systemgesteuert" ^[roman-lokalitaeten-konzept-und-ausarbeitung.md:L294]. Confidentiality is a system parameter:
„Vertraulichkeit ist systemdefiniert (d.h. nicht absolut)." ^[roman-lokalitaeten-konzept-und-ausarbeitung.md:L298]
