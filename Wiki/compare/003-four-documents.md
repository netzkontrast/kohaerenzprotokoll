# Compare — four censuses, three `theorie-physik` and one `worldbuilding`

The fourth document was **chosen** using knowledge of the first three; it was
**extracted** without any. That distinction is the rule, and it is worth stating
because the selection was deliberate: `guardians-und-kern-welten-konzept` is
dated the same day as document 1 and titled after the two terms document 1 uses
without defining.

*(Which category to read next came from `scripts/profile.py --summary`:
`worldbuilding` has a median of **2 headings** against `theorie-physik`'s 23, the
sharpest structural contrast in the corpus.)*

## The selection paid

Document 1 recorded three terms as used-but-undefined. Document 4, **from the
same day**, defines all three:

| term | document 1 | document 4 |
|---|---|---|
| `Guardians` | 3 occurrences, all in dependent clauses; „spezialisierte Agenten dieses Entropie-Managements" ^[entropie-aegis.md:L93] and nothing else | **five named Guardians**, each with nine filled fields — domain, mandate, epistemology, strengths, blind spot |
| `Kern-Welten` | 1 occurrence, in a parenthesis, as known | **four named worlds**, each with eight filled fields, each paired to a Guardian |
| `Risse` | 3 occurrences; „Manifestationen einer Zunahme von Entropie" ^[entropie-aegis.md:L94] | 10 occurrences, **manifesting differently in each of the four worlds** |

Three `readings: 0` pages become answerable. This is what the step is for.

## What this does to comparison 002's rule

002 proposed: *of the terms present in every document, the ones the project owns
carry conflicts and the borrowed ones do not.* It rested on five terms.

**At n=4 only one term is in all four**, so that formulation has a single
instance left and cannot carry the weight. Restated against *terms in three or
more*, it still holds — `AEGIS`, `Entropie`, `Kohärenz`, `Emergenz` all carry
conflicts; `Selbstorganisation`, `Kybernetik`, `Resonanz` do not — but the
evidence is now a pattern rather than a clean split.

**The lesson is about the rule, not the corpus:** a rule keyed to *shared by
all* gets weaker with every document added, because the intersection shrinks.
Keyed to *shared by three or more*, it gets stronger. Recorded so the next
comparison does not rediscover it.

## `Kohärenz` is the only term in all four, and it now has three contexts

- **system stability**, measurable — „niedrige Entropie, hohe Vorhersagbarkeit, logische Konsistenz" ^[kohaerenzprotokoll-aegis-und-systementropie.md:L27] und „über die *Redundanz*" ^[kohaerenzprotokoll-aegis-und-systementropie.md:L27]
- **truth by self-consistency** — the ZTV validity criterion, criticised as
  „extreme Form des epistemischen Kohärentismus" ^[aegis-emergenz-aus-der-leere.md:L67]
- **the name of the system itself** — „Kohärenz-Programm", six times
  ^[guardians-und-kern-welten-konzept.md:L24,36,49,74]

The third is not a fourth sense so much as the word becoming a proper noun. It is
recorded because a term page that collects senses would otherwise file the
system's own name as a definition of coherence.

## `Partnerin` — a third surface, and the four read documents never link it

30 occurrences in document 4, **zero in the other three.** It is the external
presence every Guardian is blind to, and it has its own field on every world —
`Partnerin-Echos hier`.

Documents 1 and 3 call the same role `Julia`. Document 4 never uses that name.

**A corpus-level check was run because the pairwise comparison could not answer
it**, and it corrects the obvious conclusion:

| | documents |
|---|--:|
| using `Partnerin` | **23** |
| of those, also using `Juna` or `Julia` | **17** |
| using `Partnerin` alone | 6 |

So the link **does** exist in the corpus — in 17 documents, none of them among
the four read. The honest statement is *the four read documents never link them*,
not *the corpus never links them*, and only a check outside the comparison could
tell the two apart.

**This is a finding about the step itself.** A comparison of n censuses answers
questions about those n documents. Anything of the form *does the corpus ever…*
needs a separate check against all 346, and the two must not be confused.
