## Reading — `monstergruppe-babymonstergruppe-fragmentierung-erzaehlung`, 2025-04-23, the coset-space report — DID as the metaphor for the coset space

The coset-space report names DID as the state that Kael's fragmentation resembles: „ähnlich einer dissoziativen Identitätsstörung, DID“ ^[?]. It reads the coset space as the set of fragments, in the words „oder alternativen Zustände“ ^[?], and the Alter as its cosets: „die verschiedenen Alter-Zustände symbolisieren“ ^[?]. It ties the missing group operation to a core feature of DID: „den Verlust eines einzelnen, kohärenten operativen Selbst, ein Kernmerkmal von DID“ ^[?], and in the earlier section phrases it as „spiegelt den Verlust eines einheitlichen, kohärenten operativen Selbst bei DID wider“ ^[?]. On the cause it says that the mathematics offers „eine starke Analogie für die überwältigende Wirkung von Traumata“ ^[?]. The summary of the fit: „Dies passt hervorragend zur DID-Metapher“ ^[?].
