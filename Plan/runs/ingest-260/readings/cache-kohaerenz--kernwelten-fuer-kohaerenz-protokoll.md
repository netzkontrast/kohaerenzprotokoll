## Reading — `kernwelten-fuer-kohaerenz-protokoll`, 2025-04-27, the Kernwelten design report — Cache Kohärenz as the character dynamic the worlds must enable

The Kernwelten design report frames `Cache Kohärenz` as identity fragmentation: „Kaels Identität ist in inkohärente“ ^[?] caches, each dominant in one world, and „Dies manifestiert sich in begrenzten/verzerrten Erinnerungen, widersprüchlichen Impulsen/Fähigkeiten und Desorientierung bei Übergängen.“ ^[?] It says: „Dies ist die zentrale Charakterdynamik, die die Welten ermöglichen müssen.“ ^[?] It maps the worlds to IFS part types (a framework the report brings in): „Co₁ = Manager-dominant (Logik, Kontrolle).“ ^[?], „McL = Relationale Teile (Manager/Exilanten fokussiert auf Verbindung/Angst vor Ablehnung).“ ^[?], „B = Exilant/Feuerbekämpfer-dominant (roher Schmerz, Angst, reaktive Bewältigung).“ ^[?] and „Ly = Selbst/Kreative Teile (Potential, Intuition).“ ^[?] It judges the framework: „Ein mächtiges Framework für Cache Kohärenz.“ ^[?]
