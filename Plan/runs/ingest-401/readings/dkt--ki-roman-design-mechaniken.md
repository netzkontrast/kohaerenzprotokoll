## Reading — `ki-roman-design-mechaniken`, 2026-03-02, the game-design analysis — the Dual Kernel Theory as a rule set for validating player input

The game-design analysis proposes mechanics for an interactive game and introduces the project as one that links „Hard Science-Fiction, Systemtheorie, die fiktive“ ^[?] Dual Kernel Theory (DKT) with dissociative trauma psychology. In its third mechanic, a language model validates player-written additions to the world by checking „ob der semantische Vektor dieses neuen Kontexts logisch mit den Gesetzen der Dual Kernel Theory übereinstimmt“ ^[?]; the proposal makes the theory the test an input must pass to become permanent in the game.
