## Open observations (prose, not candidates — no line below starts with `- `)

„Wächter" and its compounds never appear as a proper name for the collective
AEGIS agents in this document — that name is always the English loanword
"Guardians". Instead the German root surfaces four separate times, each for a
different referent. Limina is called "Die Wächterin / Schwellenhüterin"
(an Alter, a Gatekeeper). Cerberus's manifestation is described as possibly
"bedrohliche Wächterfiguren". The Regel-Exekutor (Einheit 734) can appear "in
KW3 als aggressiver Wächter". Praetor "kann sich als Krieger, Wächter oder
starkes Tier sehen". A fifth, related but distinct compound, "Grenzwärter", is
Terminus's own epithet, and the document itself says he "Verkörpert die
Funktion von Cerberus auf einer spezifischeren Ebene" — Terminus is explicitly
a local, minor-character embodiment of one Guardian's function, not a fifth
kind of thing.

The document reuses the name "Echo" for two unrelated referents: the Alter
"Echo (Der Kleine)" in Part II, and "Echo / Lichtfunke", a name proposed for
Junas Fragment in Part III. Same surface, two different things.

The document spells out AEGIS's acronym here: "Autonomous Entropic Gatekeeper
for Integrity Systems". I have not seen this expansion elsewhere and flag it
as a candidate reading rather than a known fact.

"Kohärenz Protokoll" (capitalised, two words) is used inside the document as
the in-world name of AEGIS's own core programming ("seine Kernprogrammierung,
das 'Kohärenz Protokoll'"), not only as the novel's title. Worth checking
against how the wiki currently treats the term.

Every one of the ten Alter profiles and eleven side-character profiles
restates the same DID role vocabulary (Gatekeeper Protector Persecutor
Caretaker Internal-Self-Helper Child-Alter/Little) as an explicit typing
applied to a named character — this document is a working-through of DID role
theory onto named characters rather than a report of it happening in the
manuscript.

Kael's own Kern-Welt assignment is stated as certain ("Beginnt in der
Konstrukt-Stadt (KW1)") but every other Alter's world-link in the summary
table carries a question mark ("(KW3)?" "(KW1)?") including Limina Eos Index
and Silas. The one-alter-one-world mapping this document proposes is
explicitly provisional even in its own table.

52 question marks and heavy hedging ("möglicherweise" "wahrscheinlich"
"könnte") run through Juna's and the Nebencharaktere's profiles — this reads
as a brainstorm/proposal document rather than a settled account.
