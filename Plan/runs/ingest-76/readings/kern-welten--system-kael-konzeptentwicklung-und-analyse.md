## Reading — `system-kael-konzeptentwicklung-und-analyse`, 2025-06-24, the concept synthesis — the four worlds as externalisations, code names and domains

The synthesis says of the worlds: „Die vier Kern-Welten (KW1-4) sind keine externen Realitäten, sondern direkte Externalisierungen von Kaels innerer psychischer Landschaft“ ^[?] It lists them with the code names `Co₁`, `McL`, `B` and `Ly` (the export keeps a gap in one name and the digit is not findable) before their longer names: `Konstrukt-Stadt`, `Resonanz-Landschaft`, `Grenzfeste` and `Möglichkeits-Garten`, each with a Wächter as domain (L160 to L164). The journey is „ein therapeutischer Prozess“ ^[?]: from „der rigiden Alltagsfassade (KW1), dem verdrängten Schmerz (KW2), den überaktiven Abwehrmechanismen (KW3) und schließlich dem Potenzial zur Heilung (KW4)“ ^[?]
