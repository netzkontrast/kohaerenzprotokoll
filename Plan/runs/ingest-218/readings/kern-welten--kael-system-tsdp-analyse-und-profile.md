## Reading — `kael-system-tsdp-analyse-und-profile`, 2025-04-28, the TSDP profile report — the Kernwelten as externalised inner conflicts and triggers

The TSDP profile report (unsigned, hedged throughout) names four worlds in section 1.2: Co₁ (Ordnung), McL (Netzwerk/Wissen), B (Chaos/Trauma) and Ly (Potentialität/Emergenz). It reads them as inner states put outside: they „fungieren als externalisierte Repräsentationen der inneren Konflikte und Zustände, die durch TSDP definiert werden“ ^[?]. It adds: „Sie bieten nicht nur eine Kulisse, sondern lösen aktiv spezifische ANP/EP-Dynamiken und Phobien aus“ ^[?].

Of B it proposes: „Die direkteste Trigger-Welt“ ^[?], one that probably activates several EPs.

For the plot it recommends: „Die Kernwelten als aktive Umgebungen nutzen, die spezifische interne Konflikte an die Oberfläche bringen“ ^[?]. Which part resonates with which world is proposed in `wahrscheinlich` and `könnte`, not assigned.
