## Reading — `kael-system-tsdp-analyse-und-profile`, 2025-04-28, the TSDP profile report — the connection to Juna/V as an external attachment object

The TSDP profile report (unsigned, hedged throughout) reads Juna/V in section 1.4 as a connection, not as a part: „Die Verbindung zu Juna/V fungiert als externes Bindungsobjekt, das das Bindungssystem innerhalb von Kael aktiviert“ ^[?].

It proposes that some parts are drawn to it: Rhys, Kiko and Lia „fühlen sich wahrscheinlich zur Verbindung hingezogen“ ^[?].

For the plot it suggests using the relation as a turning point: „Die Beziehung zu Juna/V als Katalysator für interne Konflikte (Suche vs. Abwehr) und potenziell als externe Ressource für Heilung und Ko-Regulation nutzen“ ^[?]. These are recommendations of a hedged report, with no canon claim.
