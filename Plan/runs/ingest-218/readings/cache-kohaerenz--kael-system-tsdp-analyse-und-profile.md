## Reading — `kael-system-tsdp-analyse-und-profile`, 2025-04-28, the TSDP profile report — Cache Kohärenz as the missing shared memory that makes integration hard

The TSDP profile report (unsigned, hedged throughout) ties the difficulty of integration to the problem in section 1.5. It names the cause: „Der Mangel an geteiltem Gedächtnis und Ko-Bewusstsein“ ^[?], which, it says, „macht eine koordinierte Bewegung zur Integration extrem schwierig und anfällig für Rückschläge“ ^[?].

In the plot recommendations it asks for scenes built on the problem: „Konkrete Plotpunkte entwickeln, die aus der mangelnden Ko-Bewusstheit und Amnesie resultieren“ ^[?], with one example: „Kael trifft eine Entscheidung, die durch eine un erinnerte Handlung von Nyx untergraben wird“ ^[?]. The example is the report's suggestion, not a canon event.
