# Candidates — roman-lokalitaeten-konzept-und-ausarbeitung

Written while reading, before any count. One `- term` per line.

## What this document is, noted before the list

Five parts. **Teil I** and **Teil II** are a literature review of worldbuilding
craft with 72 numbered external references; **Teil III** is a master table of
named locations across six reality levels; **Teil IV** is detailed profiles of a
subset of them, each following one fixed eleven-field template; **Teil V** is a
closing synthesis. The profile fields repeat: the capture counted ten labels
seventeen or eighteen times each.

**Two registers sit in one file and must not be harvested the same way.**
Teil I/II argue *how to build a world* and cite Foucault-adjacent craft sources,
*Inception*, *Silent Hill 2*, *Neuromancer*, *Westworld*, Bartle's player types,
liminal space, the method of loci. That is the lens, named as the lens.
Teil III/IV name *this* world's places, levels, bearers and phenomena.

**The document says what it is.** L549 calls itself a synthesis of research plus
a master list plus profiles; L553 calls it a „Welt-Bibel" for the schauplätze.

**The `Design Inspirations` field is this document's trap**, the way an imported
theory field was in the last one: Gattaca, Minority Report, Tron, Blade Runner,
Borges, Escher, The Shining, Zen-Gärten, Berliner Mauer. Every one is a
comparison, never a term of this world.

## Open while reading — to resolve before the census

- **The six levels are enumerated twice and identically.** L105 lists them as a
  profile field („KW1-4, Überwelt, Externe Ebene"), and L168–177 recapitulates
  each with a domain bearer and a psychological function. This is the first read
  source that states all four Kern-Welten with numbers, domains and bearers in
  one place.
- **`Wächter` is used analytically here**, not in a subplot title: „Sitz von
  AEGIS und den Wächtern in ihrer Systemfunktion" (L176). That is a different
  register from the last document, and it bears on the open question about how
  many things wear this word.
- **`Kern-Welt` is hyphenated throughout**, and `KW1`–`KW4` is the shorthand.
  Whether the hyphen, the number and the spelled form are one term is a
  judgement.
- **`Garten der Möglichkeiten`.** The name is close to a page the wiki may
  already hold under a different word order. Lookup will say; the decision is
  mine.
- **`Nexus-Interface`.** Same shape of question against `Nexus`.
- **`Die Große Mauer (Systemgrenze)`** shares no string with anything, and a
  border fortification is the kind of thing another source may have named
  differently. Flagged for judgement, not for lookup.
- **`Kairos/Sophia` is always slashed** in this document, exactly as `Juna/V` was
  slashed in the last one. Two names for one domain bearer, or two bearers
  sharing a domain — the document never says.
- **`Orakel/Muse` is slashed the same way** and is an Alter, not a Wächter.
- **`Echo's Resonanzraum`** carries an English genitive apostrophe in a German
  name. Possibly export damage, possibly the source's own spelling.
- **The profile template is a construct this document defines** (L105–L115,
  eleven numbered fields). It is document structure, not world vocabulary — the
  same call that rejected `Teil 1`/`Teil 2`/`Teil 3` last time.

## Added in the second half of the read

- **The document contradicts its own count and flags it.** L250 promises „ca. 30"
  detailed profiles; L543 admits „Die obigen 17 Profile sind Beispiele" and that
  a final document would carry about thirty. So Teil IV is explicitly a sample,
  and every profile in it is marked as example rather than as record.
- **L244 calls the master list „ca. 52 Orte" and „eine Rekonstruktion und
  Erweiterung".** The table also carries a `Source` column with four values —
  `Plot Teil 1`, `Konzept Doc`, `Explorative V2`, `Kontext` — which says per row
  whether the place came from an existing document or was invented here. That
  column is the most valuable thing in the table and has no analogue in anything
  read so far.
- **`Der Riss im System` is a location**, listed on the Externe Ebene with
  source `Konzept Doc` — the same word that elsewhere names a phenomenon.
- **Junas Ankerpunkt might itself be a Riss**, from the system's point of view
  (L522). That is the document putting two of its own terms in tension.
- **`Limina` is named as an Alter and as a design concept in the same file** —
  „Liminale Räume" (L152) is craft theory, `Limina` (L172) is a person. A
  substring probe will pair them and they are not one thing.

## What the extraction ran into

**Two documents in one file, and the boundary is a heading rather than a
sentence.** Teil I/II cite 72 external sources and assert nothing about this
world; Teil III/IV assert almost nothing but names, tables and sensory
description. A stance read per passage is not optional here — it is the only way
to read the file at all.

**Almost every profile sentence is conditional.** „Könnte wie eine endlose,
labyrinthartige Bibliothek wirken" (L329); „Architektur könnte fließend,
organisch oder kristallin sein" (L414). The names are asserted; the contents are
proposed. So a location is a term this document establishes, and a location's
described interior is not a reading a page can carry as a claim.

**The table is the assertion and the profiles are the proposal.** That inverts
the usual expectation that the longer passage carries more.
