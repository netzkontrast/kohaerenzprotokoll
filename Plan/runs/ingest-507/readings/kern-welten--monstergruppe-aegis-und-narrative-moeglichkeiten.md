## Reading — `monstergruppe-aegis-und-narrative-moeglichkeiten`, 2025-04-24, the Monster-group source report — four Kernwelten as laboratories for the Monster's components

The Monster-group source report names the four worlds Aegis created in its introduction as „Logik, Emotion/Paralogik, Angst/Sicherheit, Potentialität“ ^[?]; the line also names an algebra after a person, which is not quoted here. In the section on the worlds it interprets their creation as a method of isolating mathematical facets of the Monster: „Jede Welt dient als eine Art Laboratorium“ ^[?].

The world headings write the first as „Welt der Reinen Logik (Reine Logik)“ ^[?], while the introduction writes „Logik“ and the plot section writes the world of logic in running text. The report does not say whether these are the same worlds under varying names.
