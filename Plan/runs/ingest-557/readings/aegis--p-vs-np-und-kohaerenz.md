## Reading — `p-vs-np-und-kohaerenz`, 2025-04-21, the complexity report — a P-machine in an NP-world

The complexity report describes „ein hochentwickeltes System namens AEGIS“ ^[?] and proposes to model it as „AEGIS als P-Maschine in einer NP-Welt“ ^[?]: bounded to polynomial heuristics while its task is NP-hard, so that it „operiert AEGIS wahrscheinlich permanent in einem "degradierten Modus"“ ^[?]. Its summary: „AEGIS' Kampf ist ein Kampf gegen die Komplexität selbst.“ ^[?] A conditional proposal, not canon.
