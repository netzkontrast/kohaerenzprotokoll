## Reading — `prompt-entwicklung-fuer-kohaerenz-erzaehlstrang`, 2025-10-15, the strand-integration analysis — Kael as the inner strand, and Model C as its recommendation

The strand-integration analysis joins an external plot draft with Kael's TSDP strand. It places the second strand inside the protagonist: „Parallel zur kosmischen Krise entfaltet sich ein ebenso fundamentaler Konflikt im Inneren des Protagonisten Kael.“ ^[?] It reads Kael's psyche through the TSDP: „Die Analyse von Kaels Psyche basiert konsequent auf der TSDP“ ^[?]. The analysis names five parts of Kael's system and gives them roles that it calls tentative: it „ordnet ihnen basierend auf ihren Funktionen hypothetische Rollen zu“ ^[?].

It weighs three integration models. Model A puts Kael wholly inside the external plot's simulation: „Kael ist ein Bewohner dieser künstlichen Welt.“ ^[?] Its recommended Model C (the heading marks it so: „Modell C: Der vereinheitlichte Protagonist (Empfohlen)“ ^[?L191]) goes the other way: „Aris Thorne und Kael sind dieselbe Person.“ ^[?] The analysis continues that Aris Thorne, a figure of the external plot draft, „ist der nach außen gerichtete, primäre ANP des Systems, das kollektiv als Kael bekannt ist.“ ^[?] It judges this model by its own measure: „Dieses Modell ist das kraftvollste und thematisch resonanteste der drei.“ ^[?]

On the two fronts of the protagonist the analysis writes: „Der Protagonist kämpft denselben Kampf an zwei Fronten“ ^[?]. Model C is a recommendation of this analysis, not a decision of the novel; the document makes no claim of canon.
