## Reading — `romanidee-als-interaktiver-prototyp`, 2025-08-05, the CAVE prototype proposal — the ethics advice on portraying DID

In its recommendations (part IV) the proposal names the disorder only in the ethics paragraph: „Die interaktive Darstellung einer Dissoziativen Identitätsstörung und von Trauma birgt eine erhebliche ethische Verantwortung“ ^[?]. It urges involving „klinische Psychologen mit Spezialisierung auf Traumafolgestörungen“ ^[?] and, where possible, „Personen mit gelebter Erfahrung mit DID“ ^[?]. This is advice for the game; the proposal's description of Kael's system elsewhere calls it TSDP, and does not use the term here.
