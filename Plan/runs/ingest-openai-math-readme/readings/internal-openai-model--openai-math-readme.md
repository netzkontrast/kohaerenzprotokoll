## Reading — `openai-math-readme`, 2026-10-06, the openai/math readme — the unnamed model that produced the collection, and what a result cost

The readme says what produced the collection: „This repository contains mathematical manuscripts and supporting proof artifacts produced by an internal OpenAI model.“ ^[?] It never names or dates the model; for the procedure it calls it „an unreleased internal OpenAI model“ ^[?], and `GPT` stands nowhere in it (`GPT` ^[openai-math-readme.md:#0]).

Why the model was set these problems: „As part of model development, we evaluate our models on open research problems.“ ^[?] and „We expanded these evaluations after performance on our existing mathematical evaluations saturated.“ ^[?] Some results rest on others: „Some outputs build upon earlier results produced by the models.“ ^[?]

What it cost and how much it was asked: „On average, each result used three hours of ChatGPT Pro thinking compute with that model.“ ^[?] and „Over the course of the evaluation, the model was posed approximately 4,000 problems.“ ^[?] The catalogue is a selection from that output: „Aggregating the output into result families and manuscripts and requiring an appropriate level of significance led to the catalog outlined above.“ ^[?]

Not everything came from that one procedure. „Exceptions to this fixed procedure include work on a zero-free region for the Riemann zeta function and proof of the Hodge Conjecture for CM abelian varieties.“ ^[?] One writeup had a human hand: it „was human edited for readability“ ^[?]. The readme does not say what the exceptions' procedure was.
