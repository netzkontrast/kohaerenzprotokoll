A cell is the latest run's outcome: a number is the candidates staging admitted; `0` the model returned rows and none was admitted; `∅` **found nothing** (every call answered, every chunk valid, an empty container kept and checked); `n.s.` rows of a shape staging does not take; `✗` failed; `?` unverified (the record cannot show what happened); blank never run; `*` stale — the contract changed or is gone, or the source changed, since the run. Where a contract ran more than once (two models, repeats), the latest run shows here and every run is in the source's file.
