## Reading — `kohaerenz-protokoll-narrative-architektur-2`, 2025-07-29, the system plan — KW4, an NP-search world of exploration

The system plan designs KW4 as „Möglichkeits-Garten (NP-Suche - Exploration)“ ^[?], with „Kairos/Sophia (Sucher)“ ^[?] as Guardian. The aim is not a single puzzle but to find one unique state among exponentially many alternatives. It proposes: „Der Garten ist ein fraktales Labyrinth von Entscheidungen“ ^[?]; wrong paths „lässt Möglichkeiten verkümmern und sterben“ ^[?L297], which the table calls „Destruktives Chaos/Symbolischer Zerfall“ ^[?].
