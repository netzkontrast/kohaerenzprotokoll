# The wiki as a knowledge base, a knowledge graph, and a retriever over both

*2026-09-23. Written when `scripts/graph.py` and `scripts/graphrag.py` were
built, for the session that picks this up next. Everything under **What exists**
runs today; everything under **Next** does not.*

The author's direction on 2026-09-23: this should become a knowledge base and a
knowledge graph for GraphRAG. This note says what that means **here**, where the
two rules that decide everything are already written down:

- **A link is never inferred** (decision 005). A guessed edge is
  indistinguishable from a stated one once it is in the graph.
- **A page never merges readings** (P13). Where sources disagree, the page says
  so and stops.

Most GraphRAG systems break both on purpose: a model extracts entities and
relations from raw text, and a model writes a synthesized answer from community
summaries. **This one does neither**, and that is not a limitation to apologise
for — it is the thing the wiki is for. What is left of GraphRAG once both rules
hold is still the useful half: a typed graph that routes a question to the
right pages, and a retriever that returns what the sources actually said.

## What exists

### Three layers, one of them new

| layer | where | what it is | written by |
|---|---|---|---|
| knowledge base | `Sources/drive/*.md`, `Wiki/candidates/*.md` | the documents, and one page per term holding every source's reading, attributed | `sources.py`; a person |
| knowledge graph | derived by `scripts/graph.py`, never stored | typed nodes and edges, each edge carrying the file line that states it | nobody — it is a function of the pages |
| retrieval | `scripts/graphrag.py` | question → seeds → PageRank → verified quotations | nobody — it answers with the pages' own quotations |

The graph is **not a third layer** (P20): it is derived on every call in about
0.4 s, like `Wiki/index.json`, and has no content a page does not have. Repair it
by fixing the page and re-deriving (P25).

### The graph

Built from what the pages already state:

| node | from |
|---|---|
| `term:<slug>` | a page in `Wiki/candidates/`, with every surface `wiki_index` folds to it |
| `doc:<slug>` | a document a page reads (`ingested:`) or cites (`^[slug.md:Lnn]`) |
| `conflict:<Cn>` | `Wiki/conflicts/` |
| `question:<Qn>` | `Wiki/questions/` |

| edge | stated by |
|---|---|
| `links` term → term | `[[slug]]` in prose — the only term→term edge |
| `reads` term → doc | `ingested:` |
| `cites` term → doc | citations, with every cited line |
| `contests` conflict → term | `pages:` |
| `raised_by` question → term | `raised_by:` |
| `asks` question → doc | `documents:` |
| `concerns` question → conflict | `conflict:` |

And the **evidence**: every quotation on every page, with its citation, section
and verdict. The verdict comes from `quotes.pairs` / `quotes.verdict`, which
`quotes.py` itself now uses. That refactor was forced by the first run: the
graph's own pairing found 14 unresolved quotations where the checker found 4.

Exports: `--json`, `--graphml` (Gephi, networkx, any GraphRAG store that reads
GraphML), `--triples` (`subject predicate object via`, loadable into anything),
`--around <term> --hops N --mermaid` for a picture a person reads.

### The retriever

1. **Seeds** — a page is a seed when one of its folded surfaces occurs in the
   folded question. `fold()` is the rule every lookup here uses. No embeddings.
2. **Spread** — personalized PageRank from the seeds, edge types weighted
   (`links` 1.0, `contests` and `raised_by` 0.8, `concerns` 0.5, document edges
   0.3). A page two links from a seed and contested by the same conflict ranks
   above one that merely shares a word.
3. **Select** — verified quotations on the top pages, scored half by page rank
   and half by lexical overlap with the question, chosen by MMR with a
   relevance floor (λ 0.65, floor 0.15). The floor comes from `dspy-agent-skills`'
   `kp_canon_retriever.py`, whose measurement showed plain MMR choosing an
   unrelated passage over a relevant near-duplicate at every λ from 0.5 to 0.8.
   `graphrag.py selftest` reproduces that defect and asserts the floor fixes it.
4. **Return** — quotations verbatim with `doc:line`, the page and section each
   sits on, the conflicts and open questions touching the ranked pages, and the
   documents the rank reached. The conflicts come first in the reader's
   attention by design: evidence from a contested page is not an answer.

`--answer` adds one model step through `lmrun.call`. The model sees numbered
evidence and returns **numbers** and gaps; code prints the quotations. An
invalid number is dropped and named. A model that cannot type a quotation cannot
misquote one.

### What was measured

`graphrag.py bench` uses the only labels the wiki has: each question's
`raised_by` pages, each conflict's `pages`. Seventeen cases since documents 7–9 raised
C6–C12 and the author opened Q5; nine when this was written, at 40% and 58%. The case's own node is
removed from the graph before retrieving, or it would retrieve itself.

| method | recall@8 |
|---|--:|
| seeds only (the floor) | 48 <!--state:graphrag.recall_seeds-->% |
| personalized PageRank | 70 <!--state:graphrag.recall_ppr-->% |

**What that number is not.** Seventeen cases, written by the same hand that wrote
the pages, so the labels and the graph share an author. Q2 finds no seed at all
— its question names „the seven protocol terms" and none of them. Precision is
low where a conflict has one page (C1, C2) because eight pages are always
returned. It says the graph adds something over lexical seeding; it does not say
the retriever is good.

## What it cannot do

- **Anything outside the wiki.** The graph holds 93 <!--state:wiki.pages--> pages drawn from
  17 <!--state:documents.reconciled--> read documents, out of
  371 <!--state:sources.landed--> landed. A question about something no page covers finds
  no seed, and says so. The corpus is searched with qmd, which ranks and does not
  enumerate — its hits are candidates to read, never evidence.
- **Relations the prose does not mark.** `relations.py --unmarked` counts
  160 <!--state:wiki.unmarked--> mentions still unmarked; the graph does not use them, by rule.
- **Say which reading is right.** A conflict touching the ranked pages is listed,
  never resolved.
- **Judge relevance semantically.** Seeding is folded containment; a paraphrase
  of a term finds nothing. That is the first place a model could help, and the
  last place it should be allowed to decide — see *Next*.

## Next, in the order the evidence supports

1. **More labelled cases before any tuning.** Nine is a spot check. Every open
   statement under a page's `## Open` heading (`relations.py --open`) names what a
   source did not settle, often with the pages involved — a second source of
   cases. Write them as `(question, gold pages)` by hand first (P3).
2. **qmd as a second seed source, measured against the first.** A qmd hit is a
   document and a line; `graph.py`'s `cites` edges map a document line to the
   pages that cite it. Hits whose line some page cites become seeds. Compare on
   the bench against folded seeding alone — the floor already exists.
3. **Entity lists as candidate nodes, never as edges — built, the same day.**
   After `main` landed revision 3 of the entity lists and
   `Plan/runs/bilingual/stated.jsonl`, `graph.proposals()` reads both into a
   layer kept apart from `build()` (`graph.py --selftest` asserts no proposal
   edge leaks in). Entities route a question to unread documents naming it;
   `--proposals --missing` lists the entities with no page — P10's `MISSING`,
   from reading lists only. Glosses let an English question reach a German page
   under `--gloss`. Measured on the bench: 70 <!--state:graphrag.recall_ppr-->%
   with or without glosses, because no bench case is English-only. **What
   would test them is an English case set** — each `Wiki/questions/` page asked
   in English — written by hand, not translated by a model.
4. **A reviewed-page rule before `Wiki/terms/` exists.** `dspy-wiki-compile`'s
   `decision_legal()`: a new source contradicting a promoted page is flagged,
   never applied. `NOW.md` holds this open.
5. **A model proposing edges — only as a measured experiment.** `CLAUDE.md`
   already frames it: whether a model may propose an edge the prose does not
   state is to be asked *against this baseline*. The bench is that baseline. A
   proposed edge would live in a separate file, never in a page, and be scored by
   whether adding it raises recall without lowering precision.
