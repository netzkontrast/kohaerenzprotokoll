## Stance, read per passage

The document is a concept text that mostly describes: it writes in the present tense about the Überwelt as if it were an object of analysis, and opens by naming its own task, „Das vorliegende Konzept dekonstruiert die Architektur dieser Realität“ ^[L13]. The title calls it „Ontologie der Kohärenz: Die Architektonische Konstruktion der Digitalen Überwelt“ ^[L11]. Almost every sentence from L13 to L149 ends in a glued reference number (the export dropped the superscript), so each description reports a source from the reference list at L155 to L168 without saying so in words.

Two passages are prescriptive and say so with modal verbs: „Für die narrative Umsetzung im Romanprojekt“ ^[L118] the Überwelt must be staged as a place of `Algorithmischen Melancholie`, and „Visuell sollte die Überwelt durch eine“ ^[L122] shadowless transparency impress. That section (L116 to L137) is a recommendation for the novel, the rest (L13 to L114) is description of the world, and L139 to L149 is a comparison and a forecast: AEGIS „entwickelt es sich zu einer parakonsistenten Entität“ ^[L149].

The three tables (L39 to L46, L90 to L96, L130 to L137) are the document's own summaries: a protocol level, an interaction type and a sense, each row with a function or narrative rendering. The document judges itself at the end: „Das hier entwickelte Konzept der Digitalen Überwelt bietet einen präzisen Rahmen für eine Erzählung“ ^[L151]. That is a claim about its own standing and is recorded, not applied. The reference list from L155 on has among its entries „Digitale Überwelt“ ^[L156] and „Digitale Überwelt.docx“ ^[L164].
