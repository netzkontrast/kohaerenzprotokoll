## Stance, read per passage

The document is a two-stage writing commission, and it labels its two stages itself: a plan headed „Strategischer Prosa-Plan: Darstellung der Genesis-Krise“ ^[L13] and a commission headed „Finaler Prosa-Auftrag: Die Genesis-Krise von AEGIS“ ^[L155]. The first stage is a plan with sub-sections (arc, core moments, voice, tone, pacing, L13 to L153); the second is an order addressed to a writer: „Verfassen Sie eine oder mehrere Prosa-Szenen“ ^[L159]. Both are written in the imperative and the modal („muss“, „sollte“), not as report.

Inside the plan, each core moment (L38 to L112) carries two repeated labels, `Narrativer Fokus` and `Cluster-Integration`. The cluster entries are suggestions throughout: the document hedges with `möglicherweise` ^[genesis-krise-aegis-prosa-auftrag.md:#10], and writes that the Leere „sollte nicht nur als physikalisches Vakuum“ ^[L47] be shown. The document states what the fragmentation produces in the same hedged register: „Kael ist nicht identisch mit dem Ursprungs-Ich“ ^[L109].

The commission demands the concepts it lists: they are „als unverhandelbare Elemente in die Prosa integriert werden müssen“ ^[L164]. The perspective choice is introduced as a judgement: „Eine duale Perspektivstrategie erscheint am effektivsten“ ^[L116]. The summary table (L181 to L222) is a reference table with four columns, one row per theory; the bracket references `Cluster 7` ^[genesis-krise-aegis-prosa-auftrag.md:#25] point to a seventh thematic cluster that has no heading of its own in this document.

The last lines are a numbered reference list of web sources (L297 to L299, one very long line), which the document headed „Quellenangaben“ ^[L297]; it is not read as stance and none of its items is a candidate.
