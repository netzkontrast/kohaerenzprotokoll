## Stance, read per passage

The document is one evaluation report with numbered sections (1 to 8) and a reference list. It never labels a passage as plan, lock or question; it argues, and its own labels are the section headings and the fixed label `Bewertung` under each case example (`Bewertung` stands 5 times, `Bewertung` ^[charaktermodellierung-mit-aieos-schema.md:#5]).

Sections 1 and 2 (L13 to L35) set the task: „Die vorliegende Untersuchung analysiert in erschöpfender Tiefe“ ^[L15], and the passage names a danger of the schema in the same voice: „Die Gefahr besteht darin, dass die Anwendung eines solchen Schemas“ ^[L19]. The novel's world is described in the document's own report voice, with a number glued to the sentence end (35 glued reference numbers in the profile; the reference list at L205 to L221 names, among web sources, entries titled `Charaktere` ^[L207] and `Roman-Synthese mit Dual Kernel Theorie` ^[L206], so these sentences report other texts).

Sections 3 and 4 (L37 to L83) are a strengths-and-weaknesses argument: the strengths section is headed `Architektonische Stärken` ^[L37] and the weaknesses section `Architektonische Schwächen` ^[L61], and the weakness passages state a verdict: „Ein massiver konzeptioneller Fehler“ ^[L73].

Section 5 (L85 to L174) holds five case examples, each a three-column table (AIEOS node, value, justification) followed by a paragraph that opens with the label `Bewertung`. The table rows are proposals of values in the document's own mapping, not statements by the novel. Example: „Bewertung: Das Schema fasst Lex hervorragend“ ^[L106].

Section 6 (L176 to L182) is an interpretation of the third act and of the data export into reality; section 7 (L184 to L193) is a numbered list of four proposals, introduced by „Folgende architektonische Ergänzungen werden auf Basis der Dual-Kernel-Theorie“ ^[L188]; section 8 (L195 to L201) is the verdict: „ein zweischneidiges Schwert“ ^[L197].

**Omissions found only after the count.** Two names the document writes were left off the list while reading and cannot be added now that it is counted: `Lia` (a vulnerable part, L69, L128) and `EPs`, the abbreviation of Emotionale Persönlichkeitsanteile. `PSM` and `DKT` are written in parentheses and are likewise not listed as short forms. The profile and the count marks of the listed rows are not affected.

**Export damage.** The profile reports 109 backslash escapes: schema field names are written `neural\_matrix`, `amnesia\_barriers`, and in the case tables with several backslashes before the underscore, and the table cells carry `\*\*` around the column heads. The two schema fields listed with an escaped underscore count as the line writes them. Superscripted reference numbers are glued to words and sentence ends (35 in the profile), for example `AEGIS.3`. Symbols after the names of the two kernels were lost, so the line reads `Kohärenz-Kernel ()` ^[L17] in the export; the document names the symbol nowhere, and nothing here supplies it. Several table cells hold empty code spans where a list was lost, for instance the phobias of Kiko ^[L120]. The section 5 tables are flattened with an empty header row and the label row in bold.

**Quotation marks.** The document uses typographic „…“ marks for its title, for its own coinages (`Kohärenz Protokoll`) and for a quoted Wittgenstein sentence, and straight quotes for terms it takes from its sources (`Nichts Rauschens` stands in straight quotes at L27) and for field values in the tables. Which of the two kinds is a coinage and which a borrowing is not stated.

**Standing.** The document calls itself an evaluation (`Evaluation`, title at L11) and nowhere claims canon status; its statements about the novel's characters rest on its references 2, 3, 5 and 6, which the profile shows as glued numbers.
