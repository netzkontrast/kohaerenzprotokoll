## Stance, read per passage

The whole text is one voice, a report that describes itself as „Dieser Bericht dient als strategische thematische Blaupause“ ^[L5] and closes with „Dieser Bericht stellt einen detaillierten Fahrplan zur Verfügung“ ^[L323]. It names its own method in three steps ^[L9] and its structure in three parts: „Der Bericht gliedert sich in drei Hauptteile“ ^[L15]. It is a plan and an analysis, not a narrative; no passage speaks as a character.

**Part 1, the mapping (L17 to L101).** The clusters are a grouping the report makes of a catalogue it says it was given: „Eine systematische Überprüfung des im User Query bereitgestellten“ ^[L21] is how the section starts. The resonance matrix is introduced as an overview: „Diese Matrix dient als strategischer Überblick“ ^[L48]. The assignment of elements is marked as a sample: „Element-Zuordnung (exemplarisch)“ ^[L56]. Table cells hedge with question marks, for example „Hinweis?: Andeutung einer anderen Realitätsebene“ ^[L77].

**Part 2, the theory research (L103 to L231).** Each core theme has a block headed `Theoretische Fundamente` ^[kohaerenz-protokoll-thematische-tiefenanalyse.md:#4], in which the borrowed theories are described in the theories' own terms (for example „Sie werden oft von anderen Teilen unterdrückt“ ^[L115] is the report's description of a therapy model's category), and a block headed `Narrative Implikationen & Synthese` ^[kohaerenz-protokoll-thematische-tiefenanalyse.md:#4], in which the report applies them to the novel's figures. The application is proposed and hedged: „AEGIS scheint einer funktionalistischen oder informationsbasierten Ontologie zu folgen“ ^[L184], „Kritiker merken an, dass das Konzept externe Einflüsse möglicherweise unterbewertet“ ^[L155] is a report of critics of a theory, not a statement about the novel. Supporting themes are condensed in one section (L228 to L231).

**Part 3, the integration (L233 to L315).** The report turns the themes into techniques: „Dieser Teil übersetzt die theoretischen Erkenntnisse in konkrete narrative Strategien“ ^[L235]. Four tables, the Blaupausen, give per theme and per plot phase proposals for character arcs, events, world design, symbols, voice and progression; their cells are proposals phrased with the modal verb `könnte`, the adverb `vielleicht` and question marks, and the document counts 33 question marks in all.

**The conclusion and the reference list (L317 to L327).** The conclusion summarises with „Vier Kernthemen wurden priorisiert“ ^[L319]. The last section, `Quellenangaben` ^[kohaerenz-protokoll-thematische-tiefenanalyse.md:#1], is one flattened line of numbered web references (L327), not mined for candidates.
