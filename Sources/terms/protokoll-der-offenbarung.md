## Stance, read per passage

The document is an album concept for a music generator, and it marks its own parts with fixed labels. It opens with „Einleitungsprosa für das gesamte Album:“ ^[L13], and each of the fourteen songs repeats the same frame: `Einleitender Prosa-Text zum Song:` ^[protokoll-der-offenbarung.md:#14], then `Lyrics` ^[protokoll-der-offenbarung.md:#14], then `Music Style Description (For Suno):` ^[protokoll-der-offenbarung.md:#14]. The labels name fields of a template; they are not terms of the world.

- Plan, as announcement: each introductory prose looks ahead at a scene that is not yet played. The first one says „Das System steht nun vor der Tür zum Kontrollraum.“ ^[L98] The same stance recurs in every song; the album calls itself a log and a protocol, and the title line is „Das System Album: Protokoll der Offenbarung“ ^[L11].
- Report in a machine voice: every song carries a neutral system announcement, marked „Systemstimme, neutral“ ^[L29]. It states status and sector in capitals, for example „SYSTEMSTATUS: PROTOKOLL VOLLSTÄNDIG. ALLE SEKTIONEN ABGESCHLOSSEN.“ ^[L1062] and „ENDE DER AUFZEICHNUNG.“ ^[L1122].
- Lyrics in several voices: bracketed labels switch between collective voices and single parts; this is sample text in a voice, so most names there are diction rather than defined terms. One bracket reads „Kael-System-Core: Resonanzprüfung. Alle Knoten bereit?“ ^[L36], a single occurrence.
- Sound cues and style description: square brackets in the lyrics hold sound directions, and the style description closes each song, with `Dystopian Future Synth` ^[protokoll-der-offenbarung.md:#15] as its constant genre label.
- Closing passage: the last song ends with „WAS SIE LIEST, IST NICHT MEHR UNSERE VERANTWORTUNG.“ ^[L1120].

The document names no chapter and no status of its own beyond the album frame; it makes no canon claim.
