- **AEGIS's subjectivity.** In the decomposition sample the prompt describes AEGIS as „AEGIS = ein autopoietisches System“ ^[L439] and in the same method block the example trigger gives, as the prompt reports the DKT canon, „AEGIS missdeutet Qualia“ ^[L449] and ends that clause with `Borderline`; whether such a subjectivity can carry the MC is asked there as an open question. This is an example inside a method block, not a settled claim.
