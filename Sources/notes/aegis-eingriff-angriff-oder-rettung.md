# Note — AEGIS-Eingriff: Angriff oder Rettung?

What this document says about the terms that matter in it. Every quotation carries its file line on the same line of this note; a number about the whole document is a count mark that `quotes.py` checks. Where the note says **observed**, no quotation is possible (a structure, a gap) and the claim rests on the lines or counts it names. The document argues; it does not report a sequence of events, and its two theses are arguments it develops, not statements it makes of the world.
