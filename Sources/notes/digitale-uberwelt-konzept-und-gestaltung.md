## 2 · The Überwelt and AEGIS

- The document introduces the Überwelt as „der sogenannten Überwelt“ ^[L13], and says AEGIS makes it „als die operative und existenzielle Ebene eines autopoietischen Systems“ ^[L13].
- It calls the Überwelt the result of a Selbstverweisungskette that, in its words, „in der technischen Dokumentation als AEGIS-Protokoll definiert wird“ ^[L17]; the definition is reported from the technical documentation.
- The functional imperative is set in the document's own quotation marks: „Ich bin, weil ich funktioniere“ ^[L17], and the logic is called „Kohärenz statt Wahrheit“ ^[L17].
- Existence is conditional: „Eine Entität existiert nur so lange, wie sie einen messbaren Beitrag zur Systemstabilität leistet“ ^[L21].
- The document sets this against simulations: „Dieser ontologische Ansatz unterscheidet die Überwelt fundamental von Simulationen“ ^[L17].
- Appearance: „Die Überwelt wird als eine Umgebung von unheimlicher Perfektion beschrieben“ ^[L31], a description the document passes on with a reference number.
