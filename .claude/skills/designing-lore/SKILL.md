# Designing Lore

Build the deep memory layer of fictional worlds.

## Process

1. **Mythic Origin** — sacrifice genesis, fragmented god, memory-echo, recursive loop, alien catalyst
2. **Legendary Figures** — archetype, symbolic anchor, multi-region variants, current echoes
3. **Historical Eras** — name, defining event, what survived but was twisted, how history persists
4. **Relics & Artifacts** — type, functionality, origin, cultural reactions, rituals, conflict potential
5. **Cross-Reference** — link myths to biomes, civilizations, factions; mark productive contradictions

## Out of Scope

Does NOT write final files (use /writing-worldbuilding).
Does NOT design physical biomes (use /designing-worlds).
