## Discipline

- Use the exact project term when discussing structure.
- Distinguish **structural element** from **surface-language synonym**. Example: a character may seek more order in prose without that automatically meaning the Dramatica element `Control`.
- Do not invent or translate element names ad hoc.
- If legality or parent/quad membership matters, query the live engine/ontology rather than relying on remembered theory.
- Preserve project labels A (Kael/K₁) and B (AEGIS/K₀) in analytical notes to prevent cross-storyform contamination.

## Output pattern

When resolving a terminology question, report:

`Storyform → Throughline → level/slot → exact term → story expression → source path/status [K|V]`.

Never use Dramatica vocabulary as dialogue or naked exposition merely because it appears in planning documents.
